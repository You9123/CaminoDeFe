# ADR-0002: Reina-Valera 1909 como traducción incluida

- **Estado:** aceptada
- **Fecha:** 2026-09-23

## Contexto

La RVR1960 tiene derechos de autor (Sociedades Bíblicas Unidas). La app podría publicarse o venderse más adelante.

## Decisión

- Incluir la **Reina-Valera 1909** (dominio público) desde el primer día.
- Todo el contenido propio y la base del usuario guardan **referencias** (`PSA.23.1`), nunca el texto.
- `bible.db` soporta varias traducciones (`translation_id`).

## Consecuencias

- El repositorio y el instalador pueden ser públicos sin problemas de licencia.
- Agregar otra traducción (por ejemplo la RVR1960 con licencia) es solo importar datos, sin tocar el progreso del usuario.
- El texto se moderniza levemente al importarlo (ortografía, no vocabulario).
